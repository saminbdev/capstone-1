# Accounting Ledger

A command line application for managing financial transactions.

## Features
- Add deposits
- Make payments
- View transaction ledger


## How to Run
1. Open the project in IntelliJ IDEA.
2. Click on the Accounting Ledger class
3. Select RUN AccountingLedger.main()'".


## Data Storage
Transactions are stored in a file named transactions.csv in the project root directory
